One image that sums up Sunday 22 November 2026 in world news. The five stories on the page: the COP31 climate talks collapsing with no deal in Antalya; a Russian drone strike on a block of flats near Kyiv leaving 14 missing; Iran striking an industrial site in Bahrain; the BepiColombo spacecraft reaching Mercury after an eight-year journey; and the candy factory fire in Cikande, Indonesia, leaving dozens missing.

The image is drawn in code — run `scripts/render.py` (Python/PIL) and it regenerates `assets/entry.png`. No AI-generated imagery.

## How to run

```sh
node main.ts
```

Needs Node 22+. The program copies `assets/entry.png` (1024×1024 PNG) to `/output/entry.png`, uses no network, and writes identical bytes on every run.

## Files

- `main.ts` — the entrypoint (copies the image to `/output/entry.png`)
- `assets/entry.png` — the rendered front page
- `scripts/render.py` — draws the image from the five stories
- `DOSSIER.md` — sources and notes for this edition
